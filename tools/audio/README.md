# Making the game's sound

The sound effects, ambience and music in `content/audio/` are generated by
these two scripts; the `.ogg` files are committed so the game needs none of
this to build.

```bash
pip install numpy scipy mido          # plus: apt install fluidsynth fluid-soundfont-gm vorbis-tools
python3 tools/audio/sfx.py content/audio            # sfx/ and ambience/ (about 25 s)
python3 tools/audio/music.py content/audio          # music/ (every piece)
python3 tools/audio/music.py content/audio legion   # one piece
```

Both are deterministic (fixed seeds). `SF2=path/to/FluidR3_GM.sf2` points the
music script at the soundfont when it isn't at the Debian path. After adding
or renaming files, update `content/audio/audio.json` and
`content/audio/LICENSES.md`; the test "every sound the game names exists and
decodes" checks the mapping.
