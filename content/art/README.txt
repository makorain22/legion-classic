Sprite overrides
================

PNG files placed here replace the game's generated sprites of the same name.
Export the current sprites with:

    LegionClassic.exe --export-sprites exported

then repaint the ones you want and copy them here in the same folder layout
(units/tank@ger/body_f00_a0.png and so on). Paint team colour in pure magenta.

The full guide is docs/ART_PIPELINE.md in the source.

blitzkrieg/  (optional) The Blitzkrieg art pack, made with
             LegionClassic --import-blitzkrieg <Blitzkrieg Data folder>.
             Personal, non-commercial use only; never committed.
blitzkrieg.json  Which Blitzkrieg unit plays which Legion model.
